# Unit Converter

A small command-line Python program with a menu.

## Features
- Kilometers to miles and miles to kilometers
- Kilograms to pounds
- Celsius to Fahrenheit
- Even or odd checker
- Input validation with try/except

## Run
    python3 converter.py 

## What I practiced
Functions, a while loop with a menu, if/elif, the % operator, and error handling with try/except.
